# Integrated Circuit for 1.12.2

Build **redstone circuits on a 2D grid inside one block** — a backport of
**[Integrated Circuit](https://github.com/replaceitem/integrated-circuit)** by **replaceitem** (Fabric) to
**Minecraft 1.12.2** Forge / Cleanroom. Place an Integrated Circuit, open it, and draw your circuit with redstone,
repeaters, comparators, torches and more on the grid; the four sides are the block's inputs and outputs.
